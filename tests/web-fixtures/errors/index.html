Krypa fixture: errors

What this tests: how Krypa shows network and navigation failures. Each link is a deliberate failure.

Expected correct result: each link leads to an error page or error view that names the failure. Krypa does not show a blank page, does not hang, and offers a way back.

  • Missing page (HTTP 404) Expected: the server returns 404. Krypa shows the 404 page from the server, or its own not-found view. The address bar shows does-not-exist.html.
  • Refused connection (closed local port 8799) Expected: nothing listens on port 8799, so the connection is refused. Krypa shows a connection error, not a blank page. Port 8799 must stay closed while this test runs (do not start a server on it).
  • Invalid hostname (.invalid TLD) Expected: DNS lookup fails (.invalid never resolves, RFC 2606). Krypa shows a "server not found" or similar error. The lookup is caused only by tapping this link.
  • Memory pressure page (manual only) Expected: this page allocates memory only after you press its button. Nothing is allocated on load. See memory.html for the labelled test.

Note: the 404 and refused-connection results are normal here. A blank page for any of the first three links is a failure to record.
