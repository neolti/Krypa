Krypa fixture: errors (memory pressure, manual only)

Deliberate memory use. Press a button to start it. Nothing runs on load and nothing repeats automatically. Each press adds 64 MB of typed-array memory to this page. This can slow or crash the WebView or the device. Use a test device, and stop when the test has its result.

What this tests: how Krypa handles a page that holds a lot of memory (a web content process termination or memory warning).

Expected correct result: the allocated total rises in 64 MB steps. Krypa either keeps the page running, or it reloads or shows a "page crashed" view. A silent hang with no feedback is a failure. Record the total at the moment the page stopped responding.
