Krypa fixture: cross-origin (origin A)

Setup: two origins. This page is origin A: http://localhost:8765. Origin B is http://127.0.0.1:8766, the same fixture folder served on a second port. Start both servers from the fixtures folder (see README.md). Different host or port means a different origin.

Origin B used by this fixture: http://127.0.0.1:8766

What this tests: navigation and redirects between origins, and an iframe from origin B that talks to this page with postMessage.

Expected correct result: "Origin B reachable" reads "yes". Pressing "Redirect test" lands on origin B after about 1.5 s and shows "arrived at origin B". The iframe shows "frame from origin B ready".
