Krypa fixtures - index

Controlled test pages for the Krypa WebKit browser. Each fixture page states what it tests and the correct result on screen. Serve this folder over http (see README.md); do not open the files with file://.

  • basic: plain pages, anchors, long scrolling page
  • multi-page: back/forward history and per-page visit counter
  • spa: history.pushState routing, popstate, deep links
  • forms: input types, autofocus, autocomplete, submit display
  • auth: fake login with cookie and localStorage, sign-out
  • upload: file inputs (single, multiple, image capture), no upload
  • media: generated audio and video with controls
  • manifest-app: web app manifest, plus three negative manifests
  • service-worker: registration, cache source, offline page
  • external-links: target=_blank, window.open, mailto, tel, custom scheme, javascript:, data:
  • cross-origin: two origins, redirects, iframe postMessage (needs port 8766)
  • errors: 404, refused connection, invalid host, manual memory use
  • permissions: geolocation, camera, microphone, notifications
