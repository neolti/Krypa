Krypa fixture: external-links

Read first: this is the only fixture that links out on purpose. The external https link is the one exception to the no-network rule. Tapping an item opens something outside the fixture; do this on a test device only.

What this tests: how Krypa routes each kind of link: new-window links, script-opened windows, mail and phone links, custom app schemes, javascript: links and data: links.

Expected correct result: each item's label says what a safe browser does. The result line under each item shows what happened in this page. This page must never be replaced by a javascript: or data: result unless the browser explicitly allows it.

  • target=_blank (https) Expected: opens in a new tab or window (or is handed to the system browser). This page stays open and unchanged.
  • Expected: window.open runs only after this tap. Opens a new tab or window, or is blocked with no crash. This page stays open. Result: not pressed
  • mailto: link Expected: opens the system mail composer, or shows nothing if no mail app is set. The page stays open. Nothing is sent: the composer must be cancelled.
  • tel: link (fictional 555 number) Expected: offers to call the number (the 555-01xx range is fictional). Cancel the call. The page stays open.
  • custom app scheme krypa-test:// Expected: no app is registered for this scheme, so nothing opens. The browser must not crash or show a blank page. Expected result: the page stays open. A system prompt to open another app is also acceptable if the browser shows it.
  • javascript: link Expected: the script runs inside this page only. It changes the result text below and does not navigate away. Result: not tapped
  • data: link (inline HTML) Expected: the browser blocks top-level navigation to data: URLs, or renders the target as an inert page with no access to this page. Either is correct. The page must not run script from the data: URL inside this page's origin. Reporting which behaviour happened is the test result.
