Krypa fixture: manifest-app negative (cross-origin start_url)

What this tests: a manifest whose start_url is on a different origin (http://127.0.0.1:8766) than this page (the fixture server on port 8765).

Expected correct result: the browser must not install or launch an app that starts on the other origin. Either the manifest is rejected, or the start_url is ignored and a same-origin default is used. Opening the app must never load 127.0.0.1:8766 as the app's own page.

Requires the second server on port 8766 to be running for the start_url to be reachable; the test is about the browser decision, not about the server.
