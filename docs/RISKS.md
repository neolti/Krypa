# Risk register (Phase 0)

Date: 2026-11-13. Author: WP-R. Likelihood and impact are judgment ratings (L/M/H) made from documents only, not measurements (all U). "Verified by" names the check that will turn the rating into evidence. No risk is closed; nothing has been built or run.

Evidence for each risk is in [IOS_INTEGRATION.md](IOS_INTEGRATION.md), [ANDROID_INTEGRATION.md](ANDROID_INTEGRATION.md) and [APP_STORE_COMPLIANCE.md](APP_STORE_COMPLIANCE.md); the source marks (V-doc / U) are there.

## Top five (by likelihood x impact)

1. **R1** default-browser entitlement not granted: gates service workers, passkeys, Add to Home Screen.
2. **R3** iOS text input and IME in a custom view.
3. **R2** App Review interpretation of installed web apps (2.5.8, 4.7).
4. **R4** VoiceOver on egui chrome with a 0.x adapter.
5. **R5** touch routing and overlay compositing cost.

R16 (WPE) is rated high only if Android is committed; it is excluded from the top five because Android is deferred.
